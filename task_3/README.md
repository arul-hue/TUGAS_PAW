# Tugas Individu 3 — Pengembangan Aplikasi Web

## Fungsi File
- `index.html` — Halaman formulir pendaftaran. Form memakai `method="GET"` dan mengirim field ke `detail.html` melalui query string saat tombol diklik.
- `detail.html` — Halaman detail dengan data dummy dan contoh query string. Sesuai instruksi tugas, halaman ini tidak mengambil atau memproses data dari URL.
- `style.css` — Mengatur warna, formulir, tabel, kotak, serta layout menggunakan CSS Grid/Flexbox dan media query agar tampilan menyesuaikan ukuran layar.

## Cara Menjalankan
1. Ekstrak ZIP dan buka folder proyek.
2. Buka `index.html` di browser.
3. Isi formulir lalu tekan **Lihat Detail Pendaftaran**. Query string akan terlihat pada URL browser; data di halaman detail tetap berupa data dummy.
